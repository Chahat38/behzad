# Behzad Nadeem - Portfolio (static site)

Pure HTML/CSS/JS. No build step.

## Deploy on Vercel
Option A (drag & drop): vercel.com/new -> upload this folder.
Option B (CLI): `npx vercel` inside this folder, then `npx vercel --prod`.
Option C: push to GitHub, import repo in Vercel (Framework: Other, no build command, output dir: ./).

## Edit
- Photos: IMG list near top of the script in index.html (Unsplash IDs). Replace with own files in /images if wanted.
- Portrait: add images/behzad.jpg and give the .portrait div data-k or an <img>.
- CV link: point the "Download CV" button to /cv.pdf and put the file here.
